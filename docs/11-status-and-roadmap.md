## 本次实际验证

2026-10-03 在现有 Windows 开发环境执行：

- `node scripts/check.mjs`：90 个 JavaScript 模块通过。
- `node --test`：156 项通过，0 失败、0 跳过。
- 原始运行输出见 `quality/handoff-tests.txt`，摘要见 `quality/handoff-validation.json`。

本次主要做文档和源码交接，没有重跑全套浏览器、大规模性能、OCR 或真实模型评估。`quality/` 保留此前执行的结果，其适用范围和历史状态见 [证据索引](../quality/README.md)。有测试通过不等于当前所有交互、机器环境和数据质量均已验收。

现有环境检查中曾发现服务未运行，重新启动后首页与 API 恢复；进程后来又退出一次，错误日志为空。退出根因尚未确定，不能把“本次重启成功”写成已根治。启动器不提供开机常驻服务。

## 还没有完成或尚未证实

| 类别 | 具体缺口 | 不能作出的承诺 |
| --- | --- | --- |
| 新机器复现 | Windows 主机之外、干净环境、无 Codex 环境的完整安装与浏览器验收尚未统一跑通；可选 Python/浏览器依赖需单独准备 | 任意电脑克隆后所有转换与测试立即可用 |
| 启动可靠性 | 服务退出原因、系统重启/休眠后的恢复和更明确的诊断仍需调查 | 已解决所有打不开或后台退出问题 |
| OCR 与复杂文档 | Docling 适配代码存在，依赖/模型未完成安装验证；公式、复杂表格、阅读顺序、低质量扫描需真实精度评估 | 原页正常显示就代表识别文字和 LaTeX 正确 |
| 阅读格式 | 完整 EPUB CSS/固定版式、多媒体、跨页拖选、公式内部字符选择、区域级混合识别、断点续算未完成 | 完整 EPUB/所有 PDF 场景兼容 |
| 标记与手势 | 跨页拖动、自由手写、旋转未实现；物理触屏、Ctrl+滚轮、真实输入法等仍有人工验证缺口 | 所有硬件与输入方式均已验收 |
| 外部客户端 | MCP 与文档已提供，未自动安装到用户客户端；普通豆包网页/桌面自定义 MCP 入口未核实 | 已与普通豆包客户端直接接通 |
| 人物讨论质量 | 资料范围与协议已有测试，但真实人物 20 题质量门禁和不伪造引文的模型表现仍待评估 | 已拥有人物全部知识或真实人格 |
| 真实使用 | 8 人任务、一周复访、普通 8 GiB 设备基准、长文细节与长期书库体验尚未全部验收 | 自动化通过等同可用性和性能发布门禁通过 |
| 工程维护 | 首次源码快照此前没有提交历史；CI 尚未建立；部分浏览器脚本与最新界面可能不同步；旧伴读代码未清理 | 历史 UI 报告等于对当前提交的持续验证 |
| 发布形式 | 无桌面安装包、自动更新、跨设备同步、多人协作或公网部署 | 上传 GitHub 后就有可在线使用的网站或云备份 |
