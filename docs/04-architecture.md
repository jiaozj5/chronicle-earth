# 首版实现决策

2026 年 10 月 1 日，G0 实现基线。

- 运行：Node.js 24 本机服务，绑定 127.0.0.1，浏览器作为桌面交互界面。原生 ES modules，无前端构建依赖，静态资源本地提供。
- 保存：Node 内置 SQLite，由 A1 实现事务、版本、幂等与备份。用户工作区位于 .local，默认不进入版本控制。导入到新工作区，不覆盖当前数据。
- 前端：原生 DOM 模块与统一 UI 基础；各领域挂载自己的界面，应用壳统一导航、主题和跨模块操作。避免额外技术栈增加安装负担。
- 地理：随包提供 Natural Earth 公共地理数据和本地投影资源。用户记录为空时保持空白史书，基础地名属于导航材料，不代表已探索。
- 人物：可配置的外部服务适配，密钥保留在本机服务配置；前端不回显密钥。无配置时人物资料仍可使用，对话显示服务未配置。明确范围的资料和用户选中上下文才会发送。
- 数据接口：packages/contracts/README.md 与 index.js 是当前机器实现边界。HTTP 仅承载这些能力，API 同源并限制本机 Host/Origin，不公开监听局域网。
- 运行与测试：npm start、npm test、npm run check；各模块 node:test；整体验收和性能另有命令。Playwright 可使用开发环境已有依赖，不成为普通用户运行依赖。
- G0 目录调整：A0 同时拥有 apps/server/ 与 scripts/，作为本机 HTTP 入口、启动和检查工具；其他目录所有权保持不变。

真实服务讨论和真实用户一周复访需要实际外部资源；实现与本机工程检查继续推进，缺少条件时记录对应门禁未验证，不用模拟数据冒充。
