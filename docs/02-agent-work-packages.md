# 智能体工作包

版本：v0.1。本文件中的智能体指开发智能体，不是应用里的云上人物。每项工作只有一个最终负责人；可以协作审查，但不能多人同时拥有同一业务规则或文件。

## 所有权和共同约束

| 编号 | 唯一职责 | 独占写入目录或文件 | 对外依赖 |
|---|---|---|---|
| A0 | 契约、应用壳、全局导航、跨模块装配与交付 | docs/、apps/client/、packages/contracts/、packages/ui/、tests/contract-fixtures/、根构建配置与依赖锁文件 | 用户产品边界；各模块公共接口 |
| A1 | 权威数据、版本、事务、全文索引、附件与备份 | packages/workspace/，其内部迁移及测试 | A0 契约 |
| A2 | 草稿、记录、阅读目录、检索展示、预言 | features/chronicle/ 及局部测试 | A1、A3 公共能力；A0 导航与 UI |
| A3 | 时间规则、地点目录、地图聚合与探索投影 | features/atlas/ 及局部测试 | A1 已提交对象与事件；A0 契约 |
| A4 | 云上文稿、知识项、来源、引用关系 | features/knowledge/ 及局部测试 | A1；A2 记录读取；A0 导航 |
| A5 | 人物、资料范围、讨论、引用验证、采纳提案 | features/personas/ 及局部测试 | A1 来源检索；A4 来源；A0 采纳分派 |
| A6 | 独立集成验收、压力数据、故障注入、体验证据 | tests/acceptance/、tests/performance/、tests/fixtures/、quality/ | 各模块可运行版本与 A0 装配 |

表中是逻辑目录；A0 可在 G0 随技术选型统一调整一次，并同时更新本表。进入并行阶段后不得由各智能体自行迁移目录或改名公共入口。

- 各模块仅通过公共接口调用其他模块，不直接导入对方内部实现，不自行写对方拥有的对象类型。
- A1 提供通用存储，不决定史书、地点、人物的业务含义。各业务负责人提供校验与命令组合。
- 共享类型、全局样式、应用路由、根依赖与锁文件只由 A0 修改。需要变更时提交具体提案或补丁，由 A0 统一应用。
- 模块内测试与实现同属业务负责人；A6 保持独立的跨模块测试和结论。A6 报告缺陷，由原负责人修复，不越界直接修业务文件。
- 允许使用共享契约夹具独立开发，但必须明确写出哪些依赖为模拟。最终验收不能使用模拟持久化、模拟地图计数或预设人物回答替代真实能力。
- 模块日志和交接记录写在各自目录内。工程状态不通过修改根说明、公共契约或其他负责人的文件传递。
- 没有适用安全或平台约束时，模块内可逆实现选择由负责人直接完成，无需重复找用户确认。

## A0 契约与集成

工程目标：让所有模块在一套共同含义和可运行入口上工作，并对完整使用闭环负责。

必须交付：

1. 选定一个首发运行方式、统一语言/运行时与构建方式、持久化边界、地图资源方式和可替换的推理服务接口；在架构决策中写明取舍。
2. 将共享契约转换为可检查的数据结构、接口、统一错误及版本规则；提供最小夹具和契约检查命令。
3. 初始化目录、唯一依赖锁文件、开发/构建/检查入口。具体命令写入根使用说明，其他模块不能分别建立互不相容的工程。
4. 提供全局记录入口、云上云下导航、统一保存状态与通知、返回 token、基础可访问控件、布局容器。
5. 对接跨模块流程，包括记录定位、引用跳转、人物讨论上下文、采纳分派、返回编辑现场、导出恢复入口。
6. 维护范围与接口变更记录，收集各模块交付报告，组织门禁验收与最终交付说明。

无权：以实现方便为由删除云上或人物闭环；把先前示意当已确认界面；绕过 A6 数据完整性失败强行标记已通过。

完成条件：G0 通过；G1—G4 的集成入口与证据可复现；无未声明的模拟依赖。A0 对端到端贯通承担最终责任，不代替各模块的局部质量责任。

## A1 工作空间与数据

工程目标：保证一个内容只有一个身份，成功保存可恢复，所有投影和索引可以从权威数据重建。

必须交付：

1. 对象读取、版本读取、带期望版本的原子写入、幂等重试、软删除恢复和变更序列。
2. 草稿与正式对象的持久化，以及真实保存回执；磁盘或存储失败的可识别错误。
3. 按可用中文文本检索、类型/状态过滤、稳定分页；关键词搜索为必需，语义检索不作为依赖。
4. 来源文本片段和指定 `{sourceId, revision}[]` 版本快照内的检索能力；禁止人物查询越过指定资料范围，或无提示改用最新版本。
5. 附件存储、完整性校验、对象到附件引用、导出包、恢复到空工作空间、迁移及迁移失败保护。
6. 写入后索引水位、索引重建、并发版本冲突；同一应用多窗口或并发任务也不得静默覆盖。

不负责：编辑器呈现、地图布局、知识关系业务判断、人物回答内容。

交付物：真实持久化服务、公共能力适配、迁移与备份格式说明、模块测试、故障恢复证据。

完成条件：C06、C07、C09、D01—D04 的服务部分通过；为 A4 主责的 C08 提供并通过固定版本契约测试；P01/P03/P04/P07 的服务部分达到目标；A2/A3/A4/A5 能使用同一组对象 ID。服务可独立交付，跨模块端到端验收由业务主责与 A0 组织。单纯内存保存不算交付。

## A2 记录与阅读

工程目标：让用户能随时留下一笔、清楚归属、方便找回，并持续阅读与修订。

必须交付：

1. 全局记录入口的业务部分、正文优先编辑、上下文标签、草稿恢复、待整理和待定位视图。
2. 普通记录与预言编辑、可选条件与依据、预言评估、首次版本入口、历史版本比较及恢复入口。
3. 地点目录、时间分组、搜索结果、稳定分页、长文阅读、标题省略时的可读派生标题。
4. 输入法组合状态、粘贴、撤销、提交重试、保存失败恢复、键盘主操作。
5. 地图或引用跳转后恢复阅读/编辑现场；缺失时空信息不阻止保存。

不负责：搜索索引内部、时间算法、地点数据库、雾层规则、模型生成与采纳路由。采纳目标为 Entry 或 PredictionReview 时，A2 负责目标业务校验与待提交变更，以及受版本保护的撤销准备；A0 组合引用和回执后提交。

交付物：可接入应用壳的编辑与阅读模块、Entry 和 PredictionReview 业务服务、局部交互测试及空/错/加载状态清单。

完成条件：R01—R06、R08—R10、T03、N01/N02 的相关操作通过；为 A4 主责的 R07 提供并通过稳定记录引用契约测试；配合 A1 通过保存与冲突测试；真实数据下完成 G1。

## A3 时间地点与地图

工程目标：地理与时间能够帮助归位和查找，记录密度增长不破坏辨认、阅读或探索语义。

必须交付：

1. 唯一的时间解析/比较/格式化模块、TimeView 操作、地点候选与歧义选择、用户自定义地点。
2. 城市推荐尺度，同时支持其他地点类型、历史名称原文和多地点；缺地理资料时仍可保存文本归属。
3. 选定范围查询、聚合入口、去重计数、已选地点显示、按尺度出现的地名与基础海陆河流信息。
4. 按已提交记录构建探索投影；支持修改、删除、恢复、重建；过滤和浏览不能改变探索资格。
5. 阅读过程中保持视野，提供可恢复地图导航；底图不可用时，地点文本选择与记录操作继续有效。
6. 地理数据来源、可用范围与不确定性说明；不得手绘虚构坐标冒充真实地图。

不负责：记录正文、记录 kind、用户观点真假、全局史实数据库。

交付物：时间/地点服务、地图模块、探索投影、稠密数据夹具、几何与标签验收证据。

完成条件：C01—C05、M01—M06、T01—T02 通过；P05 达标；一万条同城记录也不会生成一万个独立地点标记。

## A4 云上体系与来源

工程目标：支持连续写作和严密的知识构建，使证据、概念与论证可以共享、追溯和修订。

必须交付：

1. 文稿、可折叠有序目录、自有段落与引用块、公式与表格、概念/观点/问题/论证的独立身份。
2. 来源描述、文本/Markdown/摘录/链接与附件导入入口、解析状态与可定位片段。
3. 有方向的关系、正反向引用、固定版本证据、新版本提示、已删除材料提示和恢复跳转。
4. 从选中 Entry 建立知识项，保留原文引用；已有知识项可进入多份文稿，引用语义清楚。
5. 为人物模块提供资料清单、可检索内容和唯一的引用验证能力；校验对象、版本、片段、原文及是否在调用方传入的允许范围内。采纳目标为知识项或文稿时，负责目标与引用的业务校验、待提交变更及受版本保护的撤销准备，由 A0 组合回执后一并提交。

不负责：自动判断论证正确、无限知识图谱布局、自动全网搜集资料、代替用户确认采纳。

交付物：知识业务与编辑模块、来源管理、关系与反向引用服务、修订证据测试。

完成条件：K01—K06、C08、R07、N01 相关部分通过；可独立建立没有时间地点的学术体系；真实数据下完成 G2。

## A5 人物与交流

工程目标：人物基于范围明确的材料参与思考，交流成果可用且来历可追溯，模型故障不损害用户内容。

必须交付：

1. 人物名称、形象文件、交流风格和用户诠释编辑；关联资料与资料覆盖显示。
2. 以选中观点、文稿片段或记录作为上下文的一对一讨论；上下文与版本在发起前可见。
3. 构造本次允许资料范围，调用 A1 的范围内检索和 A4 的唯一引用校验能力，处理失败并区分原文/解释/推演；不得另建引用匹配算法或在无结果时扩大资料范围。
4. 推理服务适配、取消、超时、重试、失败后继续输入；保留已完成消息与中断状态。
5. 可编辑的采纳提案：用户选中目标和类型后，A2/A4/A5 分别准备业务变更，A0 组合后交 A1 原子提交；消息引用使用稳定 ID 与版本，采纳回执只在提交成功后生效，撤销遵守版本保护。
6. 合成资料的确定性测试加至少两个明确资料范围的代表性人物验收；真实服务成功与失败路径均有证据。

不负责：改写原始来源、自动把聊天收录史书、推断所有未提供资料、圆桌或自主角色社会。

交付物：人物模块、服务适配与配置说明、引用校验、讨论状态与采纳提案、资料范围及评测报告。

完成条件：A01—A07、K06、N01 相关部分通过；无真实服务时不得将回答夹具标成已实现；其余模块不因此停止开发。

## A6 独立验收

工程目标：证明应用满足既定范围、跨模块规则和长期使用条件，及时揭示未通过之处。

必须交付：

1. 固定数据生成器、时间/地点边界样本、稠密数据、资料与引用样本、版本和导出校验器。
2. 共享契约黑盒测试、完整端到端任务、数据故障注入、规模与性能运行脚本。
3. 桌面分辨率与缩放验证、中文输入和键盘流程、文字与标签可读性审查。
4. 独立于模拟依赖的验收记录：环境、版本、步骤、实际结果、未测项、缺陷负责人。
5. 用户任务验证方案与原始观察记录。没有真实参与者时，只能报告工程走查通过，不能宣布用户喜欢或用户验收完成。

无权：改变验收门槛来掩盖失败；直接改业务目录；把模型自评当真实用户反馈。

完成条件：03 文档规定的全部必过项有可重跑证据；未达项明确列出并阻止相应门禁。A6 对验收结论负责，A0 对集成修复和交付负责。

## 依赖与并行节奏

G0 之前：A0 完成基础契约与工程入口；可由其他智能体独立审查范围、契约和验收，但不各自初始化整套应用。

G0 之后，A1—A5 可以基于统一夹具并行开发各自目录。真实验收依赖如下：

| 模块 | 可独立推进 | 真正交付前必须接通 |
|---|---|---|
| A1 | 存储、版本、索引与导出测试 | A0 契约 |
| A2 | 编辑、阅读、预言交互及错误状态 | A1 持久化、A3 时空能力 |
| A3 | 时间规则、地点、地图与探索投影 | A1 真实提交事件与记录查询 |
| A4 | 文稿、知识项、引用与来源业务 | A1 持久化、A2 稳定记录读取 |
| A5 | 人物配置、讨论状态、引用验证与服务适配 | A1 检索、A4 来源、A0 采纳分派 |
| A6 | 夹具、边界测试、验收脚本 | A0 装配后的真实应用 |

只有四个并发席位时的建议调度：

1. A0 保持集成角色，A1/A2/A3 并行完成真实记录闭环。
2. A1 核心交付后，释放席位给 A4；A2/A3 修复集成并交付地图阅读。
3. 已完成模块转为按缺陷调用；释放席位给 A5 和 A6。A4/A5/A6 与 A0 并行推进知识、人物和整体验收。
4. 修复只派回原负责人，保留必要席位给验收。不得为追求同时开工而让多个智能体争改公共文件。

## 门禁

- G0 工程可开工：运行方式与存储边界确定；共同类型、公共接口、错误、夹具、目录所有权和统一检查命令齐备。
- G1 记录贯通：真实持久化 → 时空归属 → 探索 → 目录/正文 → 检索 → 导出恢复，全部可运行。
- G2 知识贯通：记录 → 固定版本引用 → 观点 → 文稿 → 返回原记录 → 修订影响提示，全部可运行。
- G3 人物贯通：明确资料范围 → 真实讨论 → 可核验引用 → 主动采纳 → 可撤销；AI 失败不破坏核心使用。
- G4 工程候选交付：契约、规模、性能、恢复、可访问性与端到端必过项均通过；没有开放的阻断缺陷。
- G5 产品试用交付：完成规定的真实用户任务测试，问题有记录且阻断问题已解决。未获得真实测试资源时，最多宣告 G4，不能假称 G5。

后续模块可提前按契约开发，但不能绕过前置门禁宣称整体完成。

## 每个工作包的任务和交接模板

派发时使用以下文本并填入编号：

> 你负责工作包 A?。先读 docs/README.md、00-project-baseline.md、01-shared-contracts.md、03-acceptance-plan.md 和本文件中你的工作包。只修改你拥有的目录，通过公共接口与其他模块协作。按当前契约实现必须交付项，不扩张首版范围。缺少依赖时可用明确标记的契约夹具推进，最终需要真实接通。共享契约或根依赖变更交给 A0。交付时报告修改范围、公共接口、验收编号与实际结果、模拟依赖、未完成项以及下一位负责人需要的信息。

交接报告固定包含：模块与提交状态、拥有目录、接口版本、真实/模拟依赖、通过的案例及命令、失败或未测案例、迁移影响、具体待协调事项。代码存在且界面可打开不等于完成；目标验收通过且依赖状态真实，才能关闭工作包。
