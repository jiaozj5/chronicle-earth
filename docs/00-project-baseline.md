# 功能范围与工程基线

版本：v0.1。状态：执行基线，应用已进入集成与验收，实际结果以 quality 证据为准。负责人：A0。产品范围的最终决定者：用户。

## 产品成立条件

首版必须闭合以下过程：随手记下 → 归属时间地点 → 地图与目录找回 → 形成观点和体系 → 与人物讨论 → 采纳并修订 → 形成未来预言 → 回顾认识变化。

记录可以从任意位置开始；地图不成为保存内容的前置条件。抽象知识可以直接在云上建立，不要求绑定地理或历史。用户无需先完成分类、考据或结构化，才能留下内容。

必须同时守住三条底线：输入不打断思路；积累增加后仍能阅读与查找；资料、用户观点和讨论生成内容的来历可以辨认。

## 首版交付边界

为使各智能体可以开工，本规格采用以下工程默认值。这些默认值是本次方案决定，不是假定用户已经验证过的偏好。

- 单人私有工作空间，桌面使用优先；一个本机工作空间是内容的权威副本。应用内阅读、书写、查询和修改无需依赖模型服务在线。
- 不把注册、登录或云同步放在核心闭环上。首版不交付多人协作和跨设备实时同步。
- 首发采用桌面可运行的交互界面。是否浏览器运行或桌面封装、运行时、框架与存储，由 A0 在 G0 内作出并记录；必须满足本文件和验收文件，不能由各模块分别选型。
- 地理浏览采用能够缩放到区域及城市尺度的低干扰视图；首版不要求立体地球、三维建筑和摄影级场景。
- 城市是默认推荐落点，地点模型同时支持聚落、地区、自然地理范围和多地点。细粒度坐标不强制，现代行政边界不作为历史内容的硬约束。
- 时间图层是可保存、命名的查询范围。首版支持过去和未来，采用前推公历作统一索引，保留其他历法的原始表述；不承诺自动换算所有历史历法。
- 云上以连续文稿、目录、知识项和有类型的关联为主。全局自由节点画布不属于首版必交付项。
- 人物首版提供可塑造的资料型人物与一对一讨论。用户可以自行添加人物；验收至少有两个资料范围明确的测试人物。未验证资料不能冒充完整全集。

## 首版功能清单

| 编号 | 必须交付的范围 | 明确完成条件 | 主要负责人 |
|---|---|---|---|
| F01 快捷记录 | 全局入口、正文优先、上下文标签、草稿恢复、待定位 | 正文一句话即可保存；时间地点可缺失；切换视图不丢草稿 | A2 |
| F02 时间地点 | 稳定地点身份与别名、多地点、年/月/日/范围/未知、命名时间视图 | 修改观看图层不复制或迁移记录；模糊时间不伪装精确 | A3 |
| F03 地图与探索 | 地理底图、地点聚合入口、时空记录数、迷雾、选择与导航 | 地点入口不随其记录条数无界增长；点亮遵守共同规则 | A3 |
| F04 阅读与找回 | 地点目录、时间分组、关键词搜索、类型筛选、长文、返回位置 | 地图保持稳定；正文有独立实底；记录可从多个入口找到 | A2，索引由 A1 提供 |
| F05 史书与预言 | 普通记录、预言、条件与依据、评估、修订历史、软删除恢复 | 预言不随日期经过自动转为史实；首次预言及修订可回看 | A2，底层版本由 A1 提供 |
| F06 云上体系 | 文稿和可折叠目录、概念、观点、问题、论证、表格、行内与块级公式 | 无地点也可建立体系；支持明确前提与结论及反向引用 | A4 |
| F07 材料与引用 | 文本、Markdown、摘录、链接、图片附件；来源范围与稳定引用 | 引用可以定位版本和片段；普通记录无来源也可保存 | A4，附件保存由 A1 提供 |
| F08 人物与交流 | 名称、形象、交流倾向、资料集合、选定内容讨论、取消与重试 | 原文、解释、推演可区分；无证据时不编造出处；可采纳进体系 | A5 |
| F09 云下云上贯通 | 记录作为支持/反驳/实例/前提，返回原文，材料变化提示 | 同一对象多处引用；修订材料不静默改变旧论证 | A4，跨模块装配由 A0 提供 |
| F10 长期保存 | 真实保存状态、修订、冲突检测、回收站、完整备份导出及恢复 | 导出恢复后对象、身份、关系和指定附件完整；失败不假称成功 | A1 |
| F11 工作空间 | 全局导航、当前上下文、可恢复返回、错误状态、键盘主流程 | 每次切换后仍知道自己在编辑什么；AI 失效不锁住核心能力 | A0 |

导入材料默认进入待整理状态。自动提取时间、地点和主题可提供建议，但不是 F01 的依赖，也不能自动确认、点亮或替用户写观点。

首版支持用户主动建立的关联，不计算“观点正确率”，不自动判断因果，不自动合并看起来相似的史实。

## 明确排除的首版内容

- 预先铺满全球历史、自动考据所有事件、自动生成用户的史书或替用户探索。
- 三维城市、历史建筑重建、街景、人物动画、VR、场景式漫游。
- 全部历史地名与行政区划演变的完整数据库。存在资料空缺时允许用户命名地点和保留原名。
- 对任何人物“已拥有其所有留世知识”的完整性承诺；全网自动收集、无限材料规模、无来源的真实人物模仿。
- 多人物自主社会、自动长期对话、圆桌辩论和后台持续推演。
- 社区、好友、公开作品平台、商业化体系、排行榜、任务奖励和探索完成率。
- 原生手机应用、多端同步、多人实时编辑；桌面窗口应能合理收窄，但移动端并非首发验收平台。
- 扫描 PDF OCR、复杂书籍解析、音视频转录、网页批量爬取、语义搜索作为必备路径。原文件可作为附件保留，未解析内容不得显示为已可检索或已供人物使用。
- 对所有内容的永久清除、复杂版本分支、自动合并冲突。首版采用可恢复软删除；清空整个工作空间的能力不属于默认范围。
- 自动执行预测结果判断、提醒和定期抓取。预言评估由用户主动写入。

## 待验证设计及责任

| 设计问题 | 当前执行基线 | 调整权限与条件 |
|---|---|---|
| 地点尺度 | 城市推荐，允许其他地理对象与多地点 | A3 可调推荐和展示；不能限制既有对象类型 |
| 探索语义 | 当前保留的已收录记录构成关注；软删除最后一条后恢复迷雾；恢复后再点亮 | 属于共享语义，A0 组织变更；不得由地图模块私改 |
| 宏观区域的点亮 | 表示该区域层面的关注，不自动代表其内部城市全部已探索 | A3 决定视觉表达，验收必须能辨别范围 |
| 地图与阅读比例 | 阅读时正文优先、地图位置稳定，具体尺寸待任务验证 | A2 与 A3 提案，A0 决定跨模块布局 |
| 云上对象结构 | 可独立引用的知识项，加连续文稿 | A4 可调整编辑表达，稳定身份与引用契约不变 |
| 人物资料范围 | 明示当前可检索资料、未解析资料及覆盖限制 | A5 实现，不得用宣传文案掩盖资料缺口 |
| 输入辅助 | 原文优先、自动识别仅作建议 | A2 决定局部方式，不得增加保存前必填分类 |

## 决策权与变更

用户决定产品目标、重大范围增加、是否引入协作或公开发布，以及对核心使用过程的改变。A0 有权在本规格内决定实现技术、目录结构、共享接口和集成顺序，无需就普通实现选择重复询问用户。各模块负责人有权决定自己目录内的实现与局部交互。

共享语义变更必须记录：问题、替代方案、受影响对象/接口/验收、旧数据如何处理、迁移或兼容策略。A0 组织受影响负责人确认，统一更新契约版本，再安排实现。改变产品目标或显著扩张首版范围才交给用户决定。

首版没有预设工期。先完成 G0 与一个持久化记录闭环，再由负责人依据真实工作量估算；不在尚未选型、没有实现证据时承诺天数。
