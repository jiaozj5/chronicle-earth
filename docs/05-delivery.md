## 实测证据

78 项单测通过。独立核心集成 23 组、云上界面 4 组、完整使用链 6 步、应用壳 4 组均有真实执行记录；Atlas 的图层与绘制另有浏览器证据。人数与任务数量不与自动化检查数量混用。

完整链已实际走通：地图选择时间地点 → 随手记录 → 固定版本形成观点 → 人物冻结上下文 → 编辑采纳 → 沿引用返回同一原记录。还验证了三条记录编入一份文稿、自有正文独立，以及导航与地图变化不暗改草稿归属。

本机性能数据采用 10,000 条记录、2,000 个知识项、20,000 条关系、约 50 MiB 来源文本和 500 MiB 附件的合成基准。真实界面反馈各测 100 次：

| 操作 | P95 |
| --- | --- |
| 正式提交到地图实际重绘 | 419.4 ms |
| 条件搜索到目录实际渲染（含防抖） | 607.8 ms |
| 时间切换到地图像素变化 | 244.9 ms |
| 停止输入到草稿持久化并显示已保存 | 390.56 ms |

三次完整备份导出约 12.49—14.36 秒，恢复约 15.05—15.86 秒；每次均比较 98,320 个修订的规范化摘要，并从恢复后的 100 个实际附件重算摘要。后来追加的测量对象仅属于测试库。

详细状态和测量边界以 [55 项验收矩阵](../quality/验收结果.md)、[真实界面性能](../quality/performance-ui.json)、[完整链路](../quality/full-chain-latest.json) 为准。
