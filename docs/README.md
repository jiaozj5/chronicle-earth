# 岁月史书工程文档

新维护者从 [最初动机与理想使用方式](10-origin-and-vision.md)、[当前实现与后续工作](11-status-and-roadmap.md)、[新窗口 Agent 维护手册](12-maintainer-guide.md) 开始，再阅读下面的领域契约与历史规格。根目录 [AGENTS.md](../AGENTS.md) 是后续开发入口。

2026-10-03 当前状态：格式转换已并入材料藏书，地图内置地名显示汉字；阅读器内聊天和模型选择已移除，使用外部 Agent 接口。`08`、`09` 和模块交接中同时保留历史测试，不应据旧报告恢复已取消的功能。

本规格面向产品负责人、开发智能体与验收智能体，定义首版范围、共享规则、独立工作包和交付门槛。工程基线 v0.1 已进入可运行应用的集成与验收阶段；运行方式见根目录 README，实际证据见 quality。目标与实测结果分开记录，不以规格替代已完成的验证。

产品目标：让用户方便地记录自己关注的世界，把零散材料发展成自己的理解，并持续推演、修正和扩展。云下以地理与时间组织关注，云上以概念、论证和人物交流组织思考。用户的史书允许主观判断、未知、矛盾和预言。

执行顺序：先完成 G0 契约与工程基础门禁，再按工作包并行实现。任何模块都不能以“页面可打开”“接口能返回”或“人物能聊天”替代完整验收。

上面的 A0—A6 工作包和并行顺序描述首版实施历史，不自动授权后续任务委派或扩大范围。人物模型连接由用户在设置中完成；真实服务质量与真实用户任务门禁保持待验，不使用模拟结果冒充。应用仅在本机运行，默认史书为空。
