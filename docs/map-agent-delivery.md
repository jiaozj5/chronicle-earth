# 地图与模型操作接口更新

日期：2026-10-02。应用版本 0.2.0。本次交付对应地图主体、浅色无框地名、自定义地点删除恢复、明确的模型操作接口。

## 使用变化

- 岁月史书默认铺满地图。时间和地点工具悬浮在左上，可折叠；地点名称直接显示为浅色文字，选中地点另有双圈和勾选。
- 点击地点打开该时空的记录目录；点击记录打开正文。「记一笔」直接打开书写面板，「收起」保留当前草稿和阅读位置，「专注阅读」扩大正文。地图变化不会替换写作中的归属。刷新保留面板状态。
- 在「图层与地点管理 → 管理自定义地点」删除地点，操作前显示关联记录数。「显示已删除地点」中可恢复。删除仅改变地点状态，原记录、地点身份、历史名称和修订均保留。内置导航地名不提供删除。
- 工作空间设置提供「让模型操作史书」，可以复制真实本机 MCP 配置。HTTP 与 MCP 共用 9 项结构化操作，详见 [接入与参数说明](06-agent-operations.md)。
- 模型写入会自动反映到地图与目录，当前正在写作的草稿保持原样。当前普通阅读可更新到最新正文，固定历史版本保持固定。

## 明确的写入规则

查地点返回确定候选及歧义，解析日期保留原始表达。新建已收录记录要求明确日期和地点 ID；不完整内容可存待整理。已有的一句话记录即使尚无时间地点，也可以由模型修改正文。未知字段和不合规则的请求返回结构化错误。

写操作必须带唯一请求标识，重试返回原持久化回执；相同标识不能用于不同内容。修改、删除和恢复要求调用方提供读取过的版本。接口不包含任意代码执行、模型设置修改或批量清空。

服务仅在本机运行。MCP 通过本地模型客户端调用；仅配置人物讨论服务不会自动为聊天客户端安装工具。实际自然语言理解效果仍需接入所选模型后验证。

## 模块责任

Atlas 智能体负责地图绘制、浮动工具及自定义地点管理；操作接口智能体负责 Schema、操作服务、幂等与领域测试；根智能体负责布局、MCP 桥、鉴权路由、外部更新同步和端到端集成。独立审查发现的草稿吞序号与未定位旧记录无法修改两项问题均已修复并加入回归。
