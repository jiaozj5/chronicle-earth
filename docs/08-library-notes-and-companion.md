# 笔记与 AI 伴读

## 做笔记

原版页面支持直接操纵区域标记：

- 点击工具栏的符号，单击页面放置，或拖动绘制。
- 已有标记可以直接拖动。选中后有八个手柄，可改变大小；点号、对号等也会缩放。
- 点击「新标记」开始下一条。选中已有标记时，符号和颜色按钮修改当前标记。
- 右侧输入笔记，停止输入约 550 毫秒后自动保存；拖动完成后自动保存。保存状态显示在笔记下方，也可手动点击保存重试。
- 方向键微调 1 像素，Shift + 方向键微调 10 像素；Esc 取消当前手势或选中，Delete 删除当前标记，Ctrl + Z 撤销，Ctrl + Shift + Z 重做。输入框内保留正常文本编辑快捷键。
- 保存失败时保留选区、位置和文字；当前浏览器会话刷新可恢复草稿。关闭浏览器会话可能清除未保存草稿。已保存批注在 SQLite 中。

文字批注依然绑定精确原文，不允许把引用拖到另一句话上。需要自由移动的符号使用原页区域标记；文字高亮或下划线从选择文字开始，再点击工具栏符号。跨页拖动、自由手写笔迹和旋转暂不支持。

移动和缩放仅更新批注层，使用动画帧合并绘制；松手后写入一次。不重新渲染 PDF，不在每次指针移动时写数据库。

## 外部 Agent 阅读和编辑

应用内聊天、模型选择和模型服务已关闭。左侧恢复完整目录与查找，目录可收起；右侧保留笔记。阅读页顶部和书架的「Agent 接口」提供 MCP 配置与使用说明。

聊天和模型选择在 Codex 或其他外部客户端中完成；用户自然语言指令由外部 Agent 转成阅读、搜索、定位、批注与校对操作。应用只提供接口、校验、保存和界面响应。

完整接入步骤与限制见 [外部 Agent 接入](../integrations/chronicle-library/README.md)，可直接交给模型的工作规范见 [Agent 使用规范](../integrations/chronicle-library/AGENT_GUIDE.md)。Codex 配置、通用 MCP JSON 和 OpenAPI 文件已在该目录生成，尚未自动安装到客户端。

46 项外部工具包含图书、转换、文字、批注、校对与阅读窗口操作。浏览器内部 reader_sync 不再出现在外部工具清单。初始化 instructions、library_agent_guide 工具、指南 resource、library-assist prompt 提供统一使用说明。HTTP 与 MCP 共用领域验证、幂等回执和修订检查。

阅读命令返回 pending 只表示下发，浏览器约 3 秒后执行，随后通过 reader_get_state 查看 commandStatus=applied 或 failed。旧心跳不会覆盖待执行命令；保存草稿失败也不会被误报成翻页完成。接口创建的精确文字批注会在原版 PDF 唯一匹配的文字层上显示，不要求 Agent 猜页面坐标。

Codex 支持本机 STDIO MCP；豆包普通网页/桌面客户端的自定义 MCP 入口尚未获官方核实，因此本项目不宣称已接通普通豆包。支持豆包模型的本机 Agent 可以复用标准接口，纯云端不能直接连接本机回环地址。
