# 图书馆与沉浸阅读

2026-10-02，依据用户手绘草图实现。进入「材料藏书」后使用独立全窗布局，左上角可回到工作空间。

## 找书

- 默认图书馆场景：木质书架、窗光和透视地板。书籍按钮都对应实际藏书，不添加虚构藏书。
- 点击场景后 W/S 走近、退后，A/D 左右移动；方向按钮可完成相同操作。Tab 可逐本选中，Enter 打开。运动只在按键期间刷新，失焦和页面隐藏时停止。
- 有手动书架时遵循手动书架；未分类书籍按书名、副标题关键词显示在「计算与智能」「数学与科学」「历史与人文」「文学与艺术」或「随手阅读」。这是显示分组，不改写原有书目或 Agent 接口中的 shelf 字段。
- 搜索、书架筛选与列表模式共用实际藏书。最多显示 200 本，超过后用搜索定位。
- 格式转换、检查结果、加入藏书仍为两个独立步骤。

## 阅读

- 默认收起外围导航和笔记，左侧为目录与查找，显示纸页、页边翻页按钮和底部进度。应用内 AI 伴读窗口已移除。
- 左右方向键、PageUp/PageDown、空格/Shift+空格翻页；页码输入和进度滑块直接定位。选中区域标记时方向键仍用于微调标记。输入笔记、选中文字时不触发阅读快捷键。
- 翻页先保存当前批注；保存失败时保留草稿并停止翻页。连续翻页串行执行并合并中间目的地，避免异步结果互相覆盖。
- 触屏页边按钮支持水平滑动，正文区域仍可选择文字、滚动、操作批注。触屏硬件手势尚未实测。
- 阅读位置按书籍、内容版本保存在本机浏览器，刷新后恢复。注释草稿继续沿用会话恢复机制。
- 「阅读设置」可切换原版/重排/校对、整页适应/适应宽度、字号和全屏；目录、笔记可收起。Esc 先取消选区，再收起面板。
- 翻页采用 240 ms 轻微位移和透视过渡；遵循系统减少动态效果设置。没有模拟拖动纸角的物理卷页。

## 滚轮、缩放与伴读目录

- 鼠标放在书页上，滚轮向下/向上翻下一页/上一页。同一次滚动的惯性不会连续跳过多页。放大后先滚动当前页，到底或到顶后停顿再滚动才翻页；左栏滚动不翻书。
- Ctrl＋滚轮（也支持 Meta）以鼠标位置为中心缩放书页，范围 50%—300%；底部加减按钮及百分比复位使用同一路径。文字层、原图、标记一起缩放。选中文字和移动标记时不由滚轮触发翻页。
- 左侧仅显示完整目录和查找，阅读页顶部「Agent 接口」提供外部 MCP 配置。对话和模型选择留在外部 Agent 客户端；应用不启动模型服务。接入、操作规范和豆包普通客户端的限制见 `08-library-notes-and-companion.md` 与 `integrations/chronicle-library/README.md`。
- 目录优先读取阅读包里的 outline，再读取原 PDF 的书签，最后使用结构化标题。PDF 书签保留层级和物理页码，展开当前章节并突出当前条目；无目录材料显示每 20 页一组的页码导航，不生成虚构章节。
- 新的原生 PDF 转换会保存书签。旧书首次读取书签不重新渲染或 OCR，不写回书籍和批注；读取结果做有界缓存，失败可重试。阅读接口新增 `outlineSource`、`outlineWarning`，其余接口兼容。
- PDF.js 用于测量字体的隐藏 canvas 已移出普通文档布局，避免拖选时整页上下偏移。

## 原页加载

转换后的单页原图优先显示，公式与图片沿用原图。PDF.js 独立载入透明文字层，不阻塞书页显示；原生 PDF 原文仍只在唯一匹配规范块时建立文字引用。扫描文字层继续使用转换时的 OCR 词框，不把 OCR 结果当作人工校对结果。

附件支持 HTTP Range、HEAD、后缀范围及 416。PDF.js 使用 64 KiB 分段读取并关闭整本自动预取。附件完整性验证对相同工作空间、未变更的文件复用；文件 size/mtime/ctime/inode 变更后重新验证。客户端只缓存最多 6 页文字、4 张原图，预取相邻页，不预加载整本书。
